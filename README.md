# GenerativeAI_CreativeIndustries

**Generative AI in Creative Industries**

A keynote-style talk of the MGT402 Group 7 report on generative AI, IP and the creative industries.

One self-contained `index.html` (no build step), served by GitHub Pages from the `main` branch.

**Controls:** → / space / click to advance, ← to go back, C for contents, N for speaker notes, F for full screen.
